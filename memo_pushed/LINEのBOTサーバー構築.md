# 目的
LINEのwebhook用のBOT serverを開発する。ユーザーのリクエストに従い、任意の処理をして値を返却する。

# 要件
- LINEのwebhook用のAPIサーバーを構築すること
- ユーザーのメッセージに応じて処理を分岐すること
- リクエストされたユーザーからユーザー情報を照合すること
- 

# 設計
## 全体
- python/fastapiを使用してAPIサーバーを構築する
- 未契約者/契約者で処理を分岐する
- 未契約者はLLMの処理を使えない

## メッセージの条件分岐
- メッセージの冒頭をみて以下の機能を呼び出す条件分岐をする
    - 冒頭  :   機能
    - 【ユーザー情報の登録】    : ユーザー情報の登録
    - それ以外のメッセージ      : 対話

## ユーザー情報の登録
- ユーザーから以下のフォーマットに従いユーザー情報を送信させる
- ユーザー情報とユーザーのLINEIDをDBに登録する
- 登録できたら、以下のメッセージを送信する
    - メッセージ    : 登録完了
- 失敗したら、以下のメッセージを送信する
    - メッセージ    : 登録失敗
### フォーマット
```
【ユーザー情報の登録】
名前    : <名前>
メールアドレス  : <メールアドレス>
ID      : <ID>
```

## メッセージ送信バッチ
- ユーザーのLINEIDとメッセージを指定してユーザーにメッセージを送信できる
- webhookサーバーから呼び出せる

## 面談予定日の調整
- 一旦以下のメッセージを返信する
    - 機能改修中

## 契約する
- 一旦以下のメッセージを返信する
    - 機能改修中
## 対話
- ユーザーのメッセージを対話エージェントに転送する
- 出力をメッセージ送信する
