# LINE BOTサーバー修正版メモに登録・なりすまし対策・契約・送信バッチの方針を反映

## 何を
- `memo/LINEのBOTサーバー構築_修正版.md` を更新した。
  - 登録の「ID」は Messaging API の `userId` とし、ユーザーには入力させずサーバー側で取得する（LIFF の場合は ID トークンをサーバー側で検証する）。登録フォーマットから ID 欄を削除した。
  - なりすまし対策: 署名検証済みの `userId` と、DBのユーザー情報の `userId` を照合する。メールアドレスの本人確認はしない（残るリスクとして明記）。
  - 1 LINE アカウント = 1ユーザー情報とし、再登録は上書きとした。
  - 契約状態の更新は別実装とし、BOTサーバーは参照のみとした。
  - メッセージ送信バッチは BOTサーバーが非同期送信時にジョブキュー経由で実行する内部処理とし、外部公開しないことにした。
  - 未決事項をクイックリプライの表示タイミングの1件のみに整理した。

## なぜ
- 修正版メモの未決事項4点について、ユーザーから方針の回答を得たため。
