# LINE BOTサーバー構築メモの修正版を作成

## 何を
- `memo/LINEのBOTサーバー構築_修正版.md` を新規作成した。
- 元メモ `memo/LINEのBOTサーバー構築.md` に、`memo/LINEのBOTサーバー構築_懸念点.md` への回答を反映した。主な変更点は以下。
  - FastAPI の別サービスにする
  - 機能の呼び出しをクイックリプライにする
  - 登録は LIFF のフォームにする
  - 未契約者には対話を提供しない
  - 見積もりと契約は別のページで行う
  - 返信は200文字程度にする
- 技術的に成り立たない回答（トーク履歴を LINE から取得する、待機メッセージのあとに Reply で返す）と、まだ回答がない項目を「未決事項」にまとめた。

## なぜ
- 懸念点への回答を元メモに反映し、`.kiro/specs/line-bot/` の requirements.md を作成する前の土台にするため。
